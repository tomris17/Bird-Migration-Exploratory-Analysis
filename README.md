# Bird Migration Exploratory Analysis Project

[![Python](https://img.shields.io/badge/Python-3.13%2B-blue.svg)](https://www.python.org/)
[![Seaborn](https://img.shields.io/badge/Seaborn-Visualizations-orange.svg)](https://seaborn.pydata.org/)

This repository contains an exploratory data analysis project exploring bird migration patterns, species flight distances, weather impacts, and migration motivations using Matplotlib and Seaborn[cite: 15].

---

## Dataset Notice
*Note: The dataset (`bird_migration_data.csv`) used in this project[cite: 15] is custom/publicly sourced for ecological analysis.*

---

## Project Workflow & Visualizations
* **Species Analysis**: Visualizing average flight distances by individual bird species using bar plots[cite: 15].
* **Migration Motivations**: Plotting the frequency distribution of various migration reasons[cite: 15].
* **Weather Impact**: Exploring temperature conditions against flight distances categorized by weather patterns[cite: 15].
* **Web Application**: Interactive deployment interface built with Streamlit.
